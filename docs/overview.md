## Tanit Documentation

Tanit is a local-first media workspace — viewer, chat, and automation in one place. Browse files, ask the assistant, run batch jobs, and wire your own workflows without leaving the app.

This knowledge base covers the pieces you compose every day: one-click **commands**, the **CLI** for scripting, **XBlox** flows for multi-step automation, and **LLM tools** for agent integrations. Enterprise deployments also have dedicated **security** and **GPO** guides.

---

| App verbs | [Tanit App Commands](./tanit-app-commands) — `app` / IPC verbs for a running UI |

**Typical path:** start with [Commands](./tanit-commands) for everyday shortcuts → use [CLI](./tanit-cli) or [XBlox](./xblox-docs) when a workflow grows → expose capabilities to the assistant via [LLM tools](./tanit-llm-tools).

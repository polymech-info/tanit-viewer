## Direction contract

THESIS: Tanit Chat is one object with many tools, not a dashboard of apps. The category default — hero name + tagline, three feature cards, a trusted-by strip, pricing, FAQ — is refused: it sells a feature list, where the product's actual mechanism is that every capability folds out of one body. The page is a multi-tool: a closed red shell that folds open, each fold-out a capability, AI as one tool among many, not the handle.

OWN-WORLD: Signal-red anodized shell (#c8362b) on near-black (#1b1a17), warm paper ground (#f3ead8) for the open tools, light steel (#e5e5e5) for pivots and rules. Components: a closed shell plate, fold-out tool panels hinged on steel pivots, hairline rules between tools, monospaced tool labels stamped into the shell, a single pull-ring as the primary action. Recognizable with all content removed: a red shell with fold-out steel panels.

STORY: The visitor sees a closed red shell, understands it is one object that holds many tools, and watches it fold open to reveal each capability. They believe Tanit Chat brings AI, files, media, and automation into one local-first workspace because the form makes "many tools, one body" literal. They pull the ring (download) to open their own.

FIRST VIEWPORT: A centered closed red shell, scaled large, fills the upper viewport. The product name "Tanit Chat" is stamped into the shell in monospaced caps; below it a one-line claim: "Many tools. One workspace. Local first." A pull-ring sits at the shell's lower edge labeled "Get Tanit Chat — free." On scroll or click, the shell folds open along a horizontal pivot: the top plate lifts to reveal the first row of fold-out tools (Files, AI, Voice), each a steel panel with a stamped label and a one-line job. The fold is the signature interaction; the shell is the thesis, not a header.

FORM: The Multi-Tool (Swiss Army knife / multi-tool product design), position 6 of 7 on the grounded list, seed key b94bf77d.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.

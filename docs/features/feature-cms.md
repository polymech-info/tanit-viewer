# Create and share from Tanit

Turn what you are working on into something you can share.

Publish a report, write an article, post a set of pictures, or share a file. Tanit uploads it to your account and gives you a link you can send to anyone.

## Reports and articles

Any Markdown file can become a web page.

Use it for things like:

- project reports and documentation
- articles and tutorials
- research notes
- product pages
- meeting summaries
- public or private reference material

Images used by the document can be uploaded with it, and Tanit automatically rewrites their links so they work on the published page.


## Share files

Upload documents, archives, models, media, or other files to your Tanit storage.

- PDFs
- spreadsheets
- CAD files
- ZIP archives
- videos
- source files
- web applications
- downloadable project material

## Create posts

Use posts for:

- progress updates
- finished work
- photo collections
- prototypes
- before-and-after results

Posts can be `public`, `listed`, or `private`.

## From the app or command line

You can publish directly from Tanit using the sharing actions in the app.

The same operations are available through:

`tanit-cli service …`

including `pages`, `files`, `posts`, `pictures`, `categories`, and `search`.

# CLI option file extensions

One option. The command name is not a file type. `pdf` does not mean pdf. `markdown` does not mean md. Read the role word, the purpose line, and the option sentence.

Return ONLY:

```json
{"accepts": null, "generates": null, "transport": null, "confidence": 3}
```

`accepts` reads. `generates` writes.

Role word:

- `in` — `generates` is null
- `out` — `accepts` is null
- `dir` — the path is a folder. `accepts` is `directory` when the command reads it. `generates` is `directory` when the command writes the folder. The other side is `none`. `none` means that side is intentionally empty, not unset. `search index` reads folders and returns no file: the input accepts `directory`, or `["directory", "any"]` when the sentence also names files, and generates `none`
- `weight` — `generates` is null. `accepts` is the weight extension named in the option sentence (`gguf`, `onnx`, `task`)
- `map` — a ribbon button. Both sides may be set. When the destination keeps `${SRC_EXT}`, both sides are the same family. A button on the Text tab is `text`, not `any`

Each side is `image`, `video`, `audio`, `office`, `text`, `any`, `directory`, `none`, a bare-extension array, or null.

`office` is only docx, xlsx, pptx. `text` is markdown, code, and other plain-text files (md, txt, json, py, …). `text` does not include pdf, docx, xlsx, pptx, or 3D. Use `["pdf"]` only when the option sentence says a PDF file. A mix of families is an array, not a group token. `file/dir` is still that file family, not `dir`.

`transport` is `local` or `http`. An http(s) URL written as a fallback next to a filesystem path stays `local`. `http` is only a VFS or CMS remote path.

`confidence` is an integer 1 through 5:

- 5 — the option sentence names the extension or the group
- 4 — the purpose line names the family and the role word names the side
- 3 — the family is clear and the exact extensions are not
- 2 — the sentence mixes file and directory, or text and path
- 1 — the type is not stated. Both sides null. Do not guess from the command name.

No globs. No explanation.
